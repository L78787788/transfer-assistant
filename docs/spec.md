# 传输助手 v1 需求

传输助手是 Windows 10/11 x64 与 Android 9+ arm64 之间的局域网原生文件传输应用。它必须支持任意两台受支持设备之间传输文件、文件夹和批量任务，并提供暂停、取消、失败重试、断点续传、历史记录与可信设备。

## 必需行为

- Flutter 负责界面，Rust `TransferCore` 直接读写文件并负责网络、加密、校验和持久化；文件字节不得经过 Dart。
- 设备通过 mDNS 自动发现，并允许使用 `IP:端口` 手动连接；所有传输仅在局域网内完成，不依赖网页、账号、云端或中继。
- 控制消息使用 Protobuf，文件数据经 TLS 1.3 加密的 TCP 数据通道传输。
- 每个 4 MiB 数据块必须经过 BLAKE3 校验，任务最多使用四条数据通道和 64 MiB 有界缓冲。
- 首次连接的两台设备必须确认相同六位验证码；信任记录固定设备证书指纹，可信设备默认仍需确认接收。
- 文件夹保留目录结构和空目录；拒绝绝对路径、父目录跳转、符号链接与 Windows 重解析点。
- 目标重名不得覆盖已有文件；暂停或中断保留部分数据，取消删除部分数据。
- 默认仅前台可发现；传输进入后台后继续，后台接收可由用户开启。
- 大文件稳定吞吐必须达到 `min(iperf3、发送盘读取、接收盘写入) * 80%`。

## 交付

- 简体中文 Flutter APP，包含附近设备、传输任务和设置三个视图。
- Windows Inno Setup EXE 与 Android arm64 签名 APK。
- 自动化测试、CI、环境检查、发布构建和性能测试脚本。
